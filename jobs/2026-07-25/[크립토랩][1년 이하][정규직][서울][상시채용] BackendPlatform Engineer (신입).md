### 소개
CryptoLab은 세계 최고 수준의 완전동형암호(FHE, HEaaN/CKKS) 기술을 보유한 회사입니다. 데이터를 암호화된 상태 그대로 안전하게 분석·활용할 수 있게 하여, 프라이버시 보호와 데이터 가치 창출을 동시에 실현합니다.

솔루션개발팀은 이 기술을 실제 고객의 문제를 해결하는 제품으로 만드는 팀입니다. 데이터를 복호화하지 않고도 안전하게 다룰 수 있게 만들어, 금융·통신처럼 데이터 보안이 특히 중요한 산업에서도 저희 기술을 믿고 쓸 수 있게 하는 것이 목표입니다.

### 주요업무
저희가 만드는 암호화 데이터 인프라는 금융·통신 등 고객사의 온프렘 또는 클라우드 환경으로 전달되는 제품입니다. 분산 데이터 백엔드, Python SDK, 보안, 빌드·배포 파이프라인이 하나의 제품으로 맞물려 돌아갑니다. 이 포지션이 가장 먼저, 가장 깊게 집중하게 될 영역은 분산 백엔드의 동시성·정합성 설계입니다.

여러 서버에 나뉘어 저장된 데이터를 안전하게 합치고 재배치하는 과정에서 생기는 동시성 문제를 분산 백엔드(Go, gRPC/protobuf)에서 스펙 수준부터 정의하고 해결합니다. 고객에게 필요한 기능을 프로토콜 정의부터 DB 마이그레이션·백엔드·데이터 처리·SDK까지 End-to-End로 설계하는 일입니다.

이 외에도 다음 영역을 함께 담당합니다.

• Python SDK: C++ 동형암호 라이브러리를 감싼 네이티브 Python 패키지를 설계·빌드합니다.
• 빌드·CI·릴리스: GitHub Actions 기반 빌드, 취약점 검증, 릴리즈를 함께 담당합니다.
• 배포·인프라: Kubernetes/Helm(GKE·EKS·OCI) 기반으로 서로 다른 클라우드·온프렘 환경에서 제품이 동일하게 동작하도록 멀티클라우드 배포와 고객 인프라 배포 검증을 담당합니다.
