### 소개
UNX(언엑스)는
AI 캐릭터에 영혼을 담아, 사람들과 살아 움직이는 관계를 만듭니다.
우리는 서브컬처 중심의 AI 캐릭터와 스토리 콘텐츠를 만들고, 그 캐릭터가 라이브로 팬과 직접 소통하며 팬덤을 키워가는 경험을 설계합니다. 미리 정해둔 서사를 소비하는 기존 콘텐츠와 달리, 우리 캐릭터는 지금 이 순간 채팅을 읽고 반응하고 관계를 쌓습니다.
현재 여러 AI 캐릭터를 치지직·틱톡·트위치·유튜브 등에서 실제로 라이브 운영 중입니다. 방송을 통해 1:N 관계의 엔터테인먼트 경험을 만들어 가고 있어요. 어떤 캐릭터가 어떤 상황에서 사람을 붙잡는지, 그 답을 데이터로 찾고 있습니다.
우리는 AI를 도구가 아니라 일하는 방식으로 씁니다. 에이전트를 활용한 실험, 자동화, 품질 고도화가 일상인 팀이에요. 지금은 소수 정예이고, 합류하는 분은 이 카테고리의 초기 문법을 직접 정의하게 됩니다.

UNX의 AI 풀스택 엔지니어는
AI 캐릭터가 실시간으로 채팅을 읽고, 판단하고, 목소리로 말합니다. 그 사이에 있는 건 전부 우리가 쓴 코드예요. 언제 말할지 정하는 루프, 수백 개 채팅 중 무엇에 반응할지 고르는 로직, 프롬프트를 조립하는 파이프라인, 오디오와 모션을 브라우저로 흘려보내는 스트림까지.
그리고 그 엔진 위에 제품이 붙습니다. 팬이 참여를 남기는 채널, 운영자가 방송을 다루는 콘솔, AI가 만든 콘텐츠를 사람이 깎는 스튜디오. 백엔드만 하거나 프론트만 해서는 어느 것도 완성되지 않습니다. 그래서 풀스택입니다.
우리에게 AI는 두 가지입니다. 만드는 대상이면서, 만드는 방법입니다. LLM을 엮어 캐릭터를 살아 움직이게 하는 동시에, 에이전트로 코드를 쓰고 사람은 설계와 판단에 집중합니다. 참고할 정답이 거의 없는 영역이라, 아는 것보다 빠르게 만들어보고 확인하는 힘이 중요합니다.

### 담당업무
이런 일을 함께하게 돼요

실시간 라이브 엔진을 만듭니다. 캐릭터가 언제 말할지 정하는 루프, 쏟아지는 채팅 중 무엇에 반응할지 고르는 선별 로직, 관계와 전개 상태를 코드가 소유하게 만드는 상태 머신. 지금은 판단의 상당 부분이 프롬프트 안에 있어서, 그걸 하나씩 코드로 꺼내오는 것이 앞으로의 일입니다.

팬이 만나는 채널을 만듭니다. 팬이 캐릭터에게 참여를 남기는 제품이예요. 로그인을 강요하지 않으면서 관계를 쌓아야 해서, 쿠키 기반 신원부터 인증까지점진적으로 올라가는 구조를 만들어야 합니다.

운영 콘솔과 콘텐츠 스튜디오를 만듭니다. 방송을 준비하고 진행 중 개입하고 결과를 판독하는 어드민, 그리고 AI가 생성한 콘텐츠를 사람이 평가하고 피드백하는 스튜디오. 지금 개발 도구(MCP) 안에서 돌아가는 흐름을 제품으로 옮기는 일입니다.

학습 루프를 닫습니다. 방송에서 무슨 일이 있었는지 남기고, 그게 다음 방송을 더 낫게 만들도록 잇습니다. 세션 로깅, 자동 리포트, 동접·리텐션 계측까지. "돌릴수록 나아진다"를 실제로 증명하는 배관입니다.

AI와 함께 만듭니다. 에이전트로 코드를 쓰고, 반복 작업은 넘기고, 사람은 구조와 판단에 집중합니다. 어떻게 하면 더 빨리·더 정확하게 만들 수 있는지를 직접 실험하고 팀에 퍼뜨리는 것도 일의 일부입니다.
우리가 쓰는 것

백엔드 : Python · FastAPI · Supabase(Postgres) · litellm · WebSocket

프론트 : Next.js · React · TypeScript · Tailwind

실시간 : WebSocket(JSON 이벤트 + 바이너리 오디오) · WebAudio · 스트리밍 TTS

렌더러 : pixi.js · three.js/VRM · Live2D

인프라 : GCP(GCE · Cloud Build) · Docker · Vercel · 온프렘 GPU(로컬 LLM·TTS)

### 자격요건
이런 분과 함께하고 싶어요

직접 만들어서 배포해본 분: 회사 경력이 아니어도 좋습니다. 사이드프로젝트·해커톤·개인 서비스 모두 괜찮습니다. 실제로 돌아가는 걸 끝까지 만들어봤는지를 봅니다. API를 설계하고 데이터를 다뤄본 경험이 중요합니다.

LLM을 붙여서 무언가를 동작하게 만들어본 분: API 호출을 넘어, 출력을 어떻게 관리하였는지가 궁금합니다.

프론트를 피하지 않는 분: 화면까지 직접 만들어야 제품이 나옵니다. 깊은 전문성보다 끝까지 붙잡는 디테일이 중요합니다.

스스로 문제를 정의하고 도구를 만들어 푸는 분: 시키는 일을 받아 하는 자리가 아닙니다.

빠르게 만들고 확인하고 고치는 사이클을 즐기는 분: 만든 게 그 날 방송에 나갑니다.

### 우대사항
이런 경험이 있다면 더욱 좋아요

실시간 시스템을 다뤄본 분: WebSocket·스트리밍·이벤트 파이프라인처럼 끊기면 바로 티 나는 것들입니다.

Next.js·React로 실제 서비스를 만들어본 분: 제품 세 개가 전부 웹이라 바로 쓰입니다.

LLM 파이프라인이나 프롬프트 구조를 설계해본 분: 프롬프트를 잘 쓰는 것과 시스템으로 만드는 건 다른 일이에요. 후자를 해봤다면 큰 강점입니다.

코딩 에이전트로 개발해본 분: 에이전트 도구를 통해 적극적으로 결과물 품질을 높여본 경험이 필요합니다. 우리가 매일 하는 방식입니다.

오디오·미디어 스트리밍을 만져본 분: 캐릭터의 목소리가 실시간으로 브라우저까지 가야 합니다.

데이터 파이프라인·계측을 만들어본 분: 학습 루프의 절반이 계측입니다.

인프라를 직접 굴려본 분: 배포·컨테이너·모니터링을 스스로 세워본 경험입니다.

서브컬처·게임·캐릭터에 애정이 있는 분: 관심있는 분야에 일을 하면 즐길 수 있습니다.
