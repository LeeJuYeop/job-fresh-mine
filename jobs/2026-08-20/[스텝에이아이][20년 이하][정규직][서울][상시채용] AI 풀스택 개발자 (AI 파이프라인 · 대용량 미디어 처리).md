### 주요업무
영상·오디오 등 대용량 미디어를 다루는 B2B AI SaaS를 함께 만들 풀스택 개발자를 찾습니다. 이미 유료 고객이 사용 중인 운영 서비스이며, 입력 한 건이 사람 손 없이 끝까지 완주하는 자동화 파이프라인이 제품의 핵심입니다.

• TypeScript(Node) 기반 API 서버와 워커 프로세스의 기능 개발·운영
• 입력 한 건이 분석 → 가공 → 외부 발행까지 완주하는 자동화 오케스트레이터 설계·개선
• Python 멀티스테이지 AI 파이프라인 개발 (STT·비전 등 외부 추론 모델과 LLM/VLM 조합)
• LLM/VLM 호출의 프롬프트 설계, 구조화 출력, 결과 검증, 품질 평가, 작업 건당 원가 통제
• ffmpeg 기반 미디어 트랜스코딩·오버레이 파이프라인과 자동 생성 템플릿 시스템
• 외부 플랫폼 OAuth 연동과 발행·성과 조회 API 대응
• Next.js 기반 운영 콘솔 개발 (리소스 관리, 편집기 미리보기, 작업 상태 대시보드)
• PostgreSQL 스키마 설계와 대용량 미디어 파일의 스토리지·수명주기 처리
• 멀티테넌시 SaaS 기반 설계와 운영 (테넌트 격리, API 키 발급·스코프, 사용량 과금)
