### 소개
(주)스피드플로어는 상하차 무인화 기술로 화물차량과 물류센터 간 기술적 공백(Missing Link)을 해소하는 물류 테크 스타트업입니다. 
자동화된 Pallet Transfer Solution부터, 자율주행 차량의 자율 접안 기술과 AMR 로봇과의 입출고 무인화 협동까지, 스피드플로어만의 독자적인 상하차 기술로 End-to-End 물류를 완성할 [로봇 소프트웨어 엔지니어 (Robotics Software · Backend)]를 찾습니다.

• 국토교통부·해양수산부 우수물류신기술(NET) 이중 지정, 녹색기술인증, 유럽 CE 인증
• 국방부 13개 부대 납품 / 우체국 및 국내 주요 물류 대기업 레퍼런스 다수 확보
• 글로벌 제조기업 시스템 납품 / 글로벌 완성차 업체 협업 진행 중
• 2026년 미국 California 현지 수출 달성 / 시리즈A 투자 진행 중

### 주요업무
[DAP 백엔드 개발]
• 장비·로봇과 통신하는 서버 API를 개발합니다.
• 작업 지시, 상태 수집, 결과 저장 구조를 설계합니다.
• 도크 자동화 플랫폼 DAP(Dock Automation Platform)의 백엔드 기능을 구현합니다.
• PostgreSQL 기반 데이터 구조를 설계합니다.

[로봇·장비 소프트웨어]
• 무인지게차·AMR·무빙플로어·도킹스테이션과 연동되는 소프트웨어를 개발합니다.
• 로봇 상태, 작업 명령, 센서 데이터를 연동합니다.
• VDA 5050·MQTT 기반 로봇 통신 구조를 이해하고 구현합니다.
• 화성 테스트베드와 고객 현장, 실제 물리 환경에서 동작하는 코드를 검증합니다.

[장비·로봇 데이터 파이프라인]
• 컨트롤박스와 로봇에서 올라오는 센서·로그 데이터를 수집합니다.
• 전류·과부하·진동·위치·작업 로그 데이터를 처리합니다.
• MQTT·메시지 큐 기반 실시간 데이터 파이프라인을 구성합니다.
• 시계열 데이터 저장·조회 구조를 설계합니다.

[현장 운영 도구]
• 물류센터·공장 현장에서 사용하는 관제 웹 기능을 개발합니다.
• 장비·로봇 상태, 작업 현황, 실증 KPI(시간당 파렛트 처리량 등)를 시각화합니다.
• 현장 피드백을 바탕으로 기능을 개선합니다.
• 백엔드, 데이터 파이프라인, UI 사이의 연결 구조를 구현합니다.

[기술 스택 (현재 MVP 기준, SW 개발 리더와 함께 재검토 가능)]
• Backend: Node.js(Express)·Python
• Data: PostgreSQL(시계열 확장 검토), Redis
• Messaging / Robot Communication: MQTT(EMQX 또는 Mosquitto), VDA 5050, REST API·WebSocket, PLC 연동(Modbus 등)
• Infra: Docker Compose, AWS 또는 GCP, 고객 현장 온프레미스 배포, Prometheus·Grafana(도입 예정)
• Frontend: React·TypeScript
• Device: ESP32·STM32 기반 컨트롤박스, PLC(LS·미쓰비시)
• 모든 기술을 알고 있을 필요는 없습니다. 다만 하나의 언어나 프레임워크로 무언가를 끝까지 만들어 본 경험은 필요합니다.

얻어가실 수 있는 경험
• 서버, 로봇, 데이터, 현장을 분리하지 않고 한 시스템으로 다루는 엔지니어로 성장할 수 있어요.
• 내가 만든 기능이 물류센터 도크와 공장 라인에서 실제로 돌아가는 것을 볼 수 있어요.
• SW 개발 리더의 코드 리뷰와 로봇·제어 엔지니어의 현장 피드백을 함께 받을 수 있어요.
