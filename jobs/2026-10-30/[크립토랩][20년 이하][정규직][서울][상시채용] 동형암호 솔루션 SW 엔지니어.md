### 주요업무
한 제품에 국한되지 않고 팀의 여러 제품을 오가며 개발합니다. 암호 라이브러리부터 백엔드, SDK, 배포까지 제품 하나가 고객에게 전달되는 전 과정을 직접 코드로 다루게 됩니다. 각 제품의 리드 엔지니어와 함께 일하며 설계 리뷰와 코드 리뷰를 통해 빠르게 성장할 수 있고, 6~12개월 뒤에는 그중 한 영역의 오너가 되는 것을 목표로 합니다.

1. 제품 기능 개발

Go 백엔드, Python SDK, C++ 암호 라이브러리 바인딩에 걸쳐 기능을 구현하고 개선합니다.
관계형 데이터베이스(Oracle, PostgreSQL 등)와 연동되는 암호화 검색 기능을 개발합니다.
키 생성·보관·회전 등 키관리 기능을 구현합니다.

2. 테스트·성능 엔지니어링

단위·통합·E2E 테스트를 설계하고 자동화합니다.
대규모 데이터셋으로 검색 성능과 정확도를 측정하는 벤치마크를 만들고 결과를 분석합니다.
프로파일링으로 병목을 찾아 개선합니다.

3. 빌드·배포 자동화

GitHub Actions 기반 빌드, 테스트, 취약점 검사, 릴리스 파이프라인을 개발하고 운영합니다.
Docker, Kubernetes/Helm 기반으로 여러 클라우드와 온프렘 환경에서 제품이 동일하게 동작하도록 배포 체계를 만듭니다.

4. 고객 환경 검증

고객 PoC를 위한 검증 환경을 구성하고, 실제 고객 데이터 규모와 형태에서 제품이 동작하는지 검증합니다.
검증 과정에서 발견한 문제를 재현하고 제품 개선으로 연결합니다.
