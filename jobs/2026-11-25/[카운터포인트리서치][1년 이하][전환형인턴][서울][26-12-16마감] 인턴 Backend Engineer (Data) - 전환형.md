카운터포인트리서치에서 Backend ​Engineer ​(전환형 ​인턴)를 모집합니다!
카운터포인트리서치는 ​스마트폰, 반도체, AI, IoT ​등 ​하이테크 산업을 ​전문으로 하는 글로벌 ​시장조사·분석 B2B ​기업입니다.
​데이터와 전문 ​애널리스트의 ​산업 ​경험을 바탕으로 시장 ​동향 ​및 경쟁 구도를 ​분석하고, ​시장 ​규모, 수요·공급, 기술 ​트렌드 등을 ​분석해 ​기업 고객에게 ​실질적인 인사이트와 ​맞춤형 ​리서치·컨설팅을 제공합니다.
고객사가 ​시장을 파악하고 ​전략적·사업적 의사결정을 내릴 수 있도록 지원하는 것이 우리의 목적입니다.

Data&AI 팀은 고객에게 전달되는 시장 데이터와 리포트의 기반이 되는 데이터를 책임집니다. 현재는 여러 형태로 흩어져 있던 리서치 데이터를 한곳에 모으고, 검증을 거쳐 분석에 바로 쓸 수 있도록 적재하며, 반복되던 수작업을 자동화하는 데이터 플랫폼을 만들고 있습니다. 나아가 이렇게 쌓은 데이터를 거버넌스와 권한 체계 위에서 관리하고, AI 챗봇 등 다양한 접점을 통해 고객에게 제공하려 합니다.

### 주요업무
• 사내 데이터 플랫폼의 API 서버를 설계하고 개발합니다.
• 구성원이 데이터를 올리고, 처리 결과를 확인하고, 조회할 수 있는 어드민·백오피스 기능을 만듭니다.
• 구성원이 쓰는 사내 업무 도구를 개발·운영하고, 수작업으로 이루어지던 집계와 리포트 작업을 자동화합니다.
• 컨테이너 기반으로 서비스를 배포·운영하고, CI/CD 파이프라인을 구축합니다.
• 여러 소스의 데이터를 수집·정제해 데이터 마트에 적재하는 파이프라인을 개발하고 운영합니다.
• 데이터 검증 과정에 AI를 활용해, 사람이 일일이 확인하던 작업을 더 효율적으로 자동화합니다.
